The graduation · Drill 6

Do it for real 🚀

Every level in the Quest was practice in a safe sandbox. This is the same loop — branch, commit, push, PR, resolve a conflict — except now it's Creator Kit building a real artifact in a real Wix repo. Nothing simulated. You finish with a live Pull Request in wix-private/creators with your name on it.

💡 The one mindset shift: you barely touch Git commands here. You tell Claude what you want and run /ck-* commands — Creator Kit does the add / commit / push / branch under the hood. The Quest taught you the gears so this feels like recognising what's happening, not memorising it.
🔧 Prerequisites (one-time): Creator Kit installed, the creators repo cloned, git/gh signed in, and push access to wix-private/creators. Missing any? Sort it in #creator-kit before you start — don't stall on setup.

The loop

  1. Get current — clean slate

    In your creators clone, run /ck-utility-master. It switches to master, pulls the latest, and updates Creator Kit. Start clean, every time — the single most-skipped step.

    ↳ Level 1 · a branch is not a folder

  2. Start your piece — one branch, one thing

    Make your own folder projects/general/git-workshop/<yourname>-<topic>/ so 20 people work at once without colliding. Open it, then /ck-new — it creates your branch and project structure.

    ↳ Level 4 · one branch, one thing

  3. Build something real — one focused skill (~15 min)

    Run one skill and let it produce a real artifact: /ck-research-competitors (or /ck-product-spec, /ck-data-query). Pick one — resist starting three. Creator Kit stages & commits it for you.

    ↳ Level 2 · staging, done for you

  4. Draft PR early — back it up now

    Don't wait until you're "done": /ck-utility-pr opens a draft Pull Request. The moment it exists, your work lives on GitHub — not just your laptop — and there's a link to share.

    ↳ Level 4 · the way out

  5. Keep going — push to the same PR

    Run a second skill or refine the first, then let Creator Kit push again. Reload the PR: the new commit is already there. No second PR, no lost work — the PR updates itself.

  6. The conversation — a PR is a comment thread

    Pair up. Comment on a neighbour's PR line. When one lands on yours, run /ck-utility-address-comments — it reads each comment and helps you reply, usually with another commit to the same branch.

    ↳ Level 5 · a PR is a conversation

🔥 The conflict finale

The scariest level was the pull conflict — and it's the one step that fights you on a real repo: seeding and re-editing a shared line on master in creators needs push rights and code ownership most people don't have. So you rehearse the conflict where you're in full control — the Quest — then learn the real-repo version.

Rehearse it in the Quest: replay the pull-conflict level. You trigger a real conflict on purpose, by yourself, and resolve it in three moves — open the file → delete the <<<<<<< / ======= / >>>>>>> markers → keep the text you want → add + commit. Identical mechanically to what happens on a Wix repo.

Then connect it to real work: on creators you never touch those markers by hand. When your branch and master disagree, run /ck-utility-sync — it pulls master in, hits the conflict, and walks you through the same choice (keep yours, take theirs, or combine), then commits and pushes for you. Same decision; Creator Kit does the git surgery.
🧑‍🏫 Facilitators: don't stage this on master in creators — branch protection and code ownership will block the mid-session push. Run the conflict in the Quest for the whole room, then demo /ck-utility-sync on your own branch (or narrate it) so everyone sees the real-repo version without anyone writing to master.

What just happened

  • The daily loop is exactly the Quest loop: get current → branch → build → draft PR → push more → resolve → merge. Same six moves, real stakes.
  • Creator Kit runs the Git for you — including resolving conflicts. Knowing the gears is what lets you trust that, not fear it.
  • A draft PR from commit one means your work is backed up and shareable the whole time — never trapped on one laptop.
  • A PR is a conversation bolted to the actual change. You're already fluent in that.
🧹 When it's merged: click GitHub's "Delete branch", then /ck-utility-master for whatever's next.
