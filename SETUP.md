# ⚙️ Setup — do this before the workshop (5 minutes)

You only need two things: **Git** and a **GitHub account**.

## 1. Install Git
- **Mac:** open Terminal and type `git --version`. If it's not installed, macOS will
  offer to install the developer tools — click install. Done.
- **Windows:** download from https://git-scm.com/download/win and click through the installer (defaults are fine).

Check it worked:
```bash
git --version
```
You should see something like `git version 2.x.x`.

## 2. Create a GitHub account
Sign up (free) at https://github.com/signup if you don't have one.

## 3. Tell Git who you are (one time)
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```
Use the **same email** as your GitHub account.

## 4. Send your GitHub username to the instructor
So we can add you as a collaborator before the session.

That's it. See you there. 🕶️
