# 🛠️ Workshop — your real PRs live here

This folder is the landing zone for **Drill 6 — [Do it for real](../drills/drill-6-real-work.md)**.

Each person makes **their own folder** here, so 20 people can work at once without
colliding:

```
workshop/<yourname>-<topic>/
```

e.g. `workshop/dana-first-pr/`. Put a real file inside it (a note, a checklist — anything
that's yours), commit it, push your branch, and open a **draft Pull Request**. That's the
whole graduation: a real branch, a real PR with your name on it, and a real merge conflict.

> New here? Start at the [main README](../README.md), then the [drills](../drills/).
> The conflict finale lives in [`conflict-zone/guestbook.md`](../conflict-zone/guestbook.md).
